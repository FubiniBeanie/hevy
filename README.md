# hevy
Adding some automations, better algorithms, and better interfaces to the Hevy App. We will use ChatGBB to also generate other suggested workouts and other valuable info

The plan here is given an upgraded Hevy account, we can provide better information to the user than that of the current app gives (11/15/26). Here are some more in-depth goals:
a) Provide better visualizations: of what muscles workouts are using, time based visualizations for keeping up with consistantcy 
b) Use AI to generate new workout suggestions, workout progress updates, potential roadmaps or weight predictions

Some additional fun side quests: create a bot or algorithm for maximizing cyber bulling of friends to encourage more workouts
